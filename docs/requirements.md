# 要件定義書

## 1. 概要

Campfires は、勉強会やコミュニティの運営者のためのイベント申込み管理アプリです。

1つのアプリの中に、独立したコミュニティがいくつも存在します。各コミュニティには1人のオーナーがいて、そこにメンバーが集まり、イベントに申し込みます。

名前は「広い野原のあちこちで焚き火（コミュニティ）が灯り、それぞれに人が集まってくる」様子から付けています。

## 2. 用語

| 用語 | 意味 |
|---|---|
| ユーザー | アカウント登録をした人 |
| コミュニティ | ユーザーが作るグループ。イベントはコミュニティの中で開かれる |
| オーナー | コミュニティを作った人。1つのコミュニティに1人 |
| 運営スタッフ | オーナーに任命されたメンバー。運営を手伝う |
| メンバー | コミュニティへの参加が承認された人 |
| イベント | コミュニティで開かれる勉強会など。定員がある |
| 申込み | メンバーがイベントに参加を申し込むこと |
| キャンセル待ち | 満席のイベントに申し込んだとき、空きを待つ状態 |

## 3. 利用者と権限

コミュニティの中での立場（ロール）は、オーナー、運営スタッフ、メンバーの3種類です。同じユーザーでも、コミュニティごとに立場が異なります。

| できること | オーナー | 運営スタッフ | メンバー | 参加していないユーザー |
|---|:-:|:-:|:-:|:-:|
| コミュニティの詳細を見る | ○ | ○ | ○ | ○ |
| コミュニティの情報を編集する | ○ | × | × | × |
| コミュニティを削除する | ○ | × | × | × |
| 参加を申請する | - | - | - | ○ |
| 参加申請を承認・却下する | ○ | ○ | × | × |
| 運営スタッフを任命・解除する | ○ | × | × | × |
| イベントを作成・編集・削除する | ○ | ○ | × | × |
| イベントの一覧・詳細を見る | ○ | ○ | ○ | ○ |
| イベントに申し込む・キャンセルする | ○ | ○ | ○ | × |
| イベントの申込者一覧を見る | ○ | ○ | × | × |
| コミュニティを退会する | × | ○ | ○ | - |

## 4. 機能一覧

### 4.1 MVP（最初に作る範囲）

| ID | 機能 | 内容 |
|---|---|---|
| F-01 | アカウント登録 | 名前、メールアドレス、パスワードで登録する |
| F-02 | ログイン・ログアウト | メールアドレスとパスワードでログインする |
| F-03 | コミュニティ作成 | 名前と説明を入力して作る。作った人がオーナーになる |
| F-04 | コミュニティ一覧・詳細 | すべてのコミュニティを一覧で見られる |
| F-05 | コミュニティ編集・削除 | オーナーだけができる |
| F-06 | 参加申請 | 参加していないユーザーが、コミュニティに参加を申請する |
| F-07 | 参加申請の承認・却下 | オーナーと運営スタッフが、申請を承認または却下する |
| F-08 | 退会 | メンバーと運営スタッフがコミュニティを抜ける |
| F-09 | 運営スタッフの任命・解除 | オーナーがメンバーを運営スタッフにする、または元に戻す |
| F-10 | イベント作成・編集・削除 | タイトル、説明、開始日時、終了日時、場所、定員を登録する |
| F-11 | イベント一覧・詳細 | コミュニティごとのイベントを見る。残りの枠数も表示する |
| F-12 | イベント申込み・キャンセル | メンバーがイベントに申し込む、または取り消す |
| F-13 | 申込者一覧 | オーナーと運営スタッフが、イベントの申込者を確認する |

### 4.2 MVP の後半で作る範囲

基本機能ができた後に作ります。このアプリの技術的な見どころです。

| ID | 機能 | 内容 |
|---|---|---|

- 画像のアップロード
- 招待リンクによる参加

## 5. 業務ルール

### 5.1 コミュニティ

- オーナーは退会できない。オーナーがやめるときは、コミュニティごと削除する
- 参加申請の状態は「申請中」「承認済み」「却下」の3つ
- 却下された人は、もう一度申請できる

### 5.2 イベントと申込み

- 申し込めるのは、そのコミュニティのメンバー（オーナーと運営スタッフを含む）だけ
- 1人が同じイベントに申し込めるのは1回だけ
- 申込み数が定員に達したら、それ以上は申し込めない（MVP の後半からは、キャンセル待ちになる）
- 終了したイベントには申し込めない
- 定員を、今の申込み数より少なくすることはできない

### 5.3 キャンセル待ち（MVP の後半）

- キャンセル待ちは、申し込んだ順に並ぶ
- 申込みがキャンセルされたら、キャンセル待ちの先頭の人が申込み済みになる
