# 画面一覧

MVP で作る画面と、その URL をまとめます。機能の ID（F-01 など）は [要件定義書](requirements.md) の機能一覧に対応しています。

## 1. 画面の一覧

| ID | 画面 | URL | 見られる人 | 対応する機能 |
|---|---|---|---|---|
| S-01 | コミュニティ一覧（トップ） | `/` | 誰でも | F-04 |
| S-02 | アカウント登録 | `/signup` | ログインしていない人 | F-01 |
| S-03 | ログイン | `/login` | ログインしていない人 | F-02 |
| S-04 | コミュニティ作成 | `/communities/new` | ログインしている人 | F-03 |
| S-05 | コミュニティ詳細 | `/communities/:communityId` | 誰でも | F-04、F-06、F-08、F-11 |
| S-06 | コミュニティ編集 | `/communities/:communityId/edit` | オーナー | F-05 |
| S-07 | メンバー管理 | `/communities/:communityId/members` | オーナー、運営スタッフ | F-07、F-09、F-19 |
| S-08 | イベント作成 | `/communities/:communityId/events/new` | オーナー、運営スタッフ | F-10 |
| S-09 | イベント詳細 | `/communities/:communityId/events/:eventId` | 誰でも | F-11、F-12 |
| S-10 | イベント編集 | `/communities/:communityId/events/:eventId/edit` | オーナー、運営スタッフ | F-10 |
| S-11 | 申込者一覧 | `/communities/:communityId/events/:eventId/applicants` | オーナー、運営スタッフ | F-13 |
| S-12 | アカウント設定 | `/account` | ログインしている人 | F-17、F-21 |
| S-13 | プライバシーポリシー | `/privacy` | 誰でも | F-18 |
| S-14 | 利用規約 | `/terms` | 誰でも | F-18 |
| S-15 | お知らせ一覧 | `/notifications` | ログインしている人 | F-20 |
| S-99 | ページが見つかりません | 上のどれにも当てはまらない URL | 誰でも | ― |

### URL の読み方

- `:communityId` のように `:` で始まる部分には、実際の番号が入ります。たとえば `/communities/3` は「3番のコミュニティの詳細」です
- イベントの URL は、コミュニティの URL の下に置いています。「イベントは必ずどれか1つのコミュニティに属する」という関係を、URL でも表すためです
- ログアウト（F-02）は画面を持たず、画面上部のボタンで行います

## 2. 各画面に置くもの

| ID | 画面 | 表示する内容 | 操作 |
|---|---|---|---|
| S-01 | コミュニティ一覧 | コミュニティの名前、説明、メンバー数 | コミュニティ詳細へ移動、コミュニティ作成へ移動 |
| S-02 | アカウント登録 | 入力欄（本名、ニックネーム、メールアドレス、パスワード。本名はほかの人に表示されないことを説明する）、プライバシーポリシーと利用規約へのリンク、「同意する」のチェック | 登録する（チェックしないと押せない） |
| S-03 | ログイン | 入力欄（メールアドレス、パスワード） | ログインする |
| S-04 | コミュニティ作成 | 入力欄（名前、説明） | 作成する |
| S-05 | コミュニティ詳細 | コミュニティの名前、説明、オーナー、自分の立場、イベントの一覧（残りの枠数つき） | 参加を申請する、退会する、編集へ移動（オーナー）、メンバー管理へ移動（オーナー、運営スタッフ）、イベント作成へ移動（オーナー、運営スタッフ） |
| S-06 | コミュニティ編集 | 入力欄（名前、説明） | 保存する、コミュニティを削除する |
| S-07 | メンバー管理 | 参加申請の一覧、メンバーの一覧と立場 | 申請を承認・却下する、運営スタッフに任命・解除する（オーナー）、除名する（オーナー。確認の画面で、申込みが自動でキャンセルされることを表示する） |
| S-08 | イベント作成 | 入力欄（タイトル、説明、開始日時、終了日時、申込み締め切り日時、場所、定員）、場所の注意書き（個人の住所を入力しない） | 作成する |
| S-09 | イベント詳細 | イベントの内容、申込み締め切り日時、定員と残りの枠数、自分の申込み状況 | 申し込む（締め切り前だけ）、キャンセルする（締め切り後は確認の画面を出す）、編集へ移動・申込者一覧へ移動（オーナー、運営スタッフ） |
| S-10 | イベント編集 | 入力欄と注意書き（S-08 と同じ） | 保存する、イベントを削除する |
| S-11 | 申込者一覧 | 申込者のニックネームと申込日時（アカウントを削除した人は「退会したユーザー」）。本名は表示しない | ― |
| S-12 | アカウント設定 | 自分の本名、ニックネーム、メールアドレス、アカウント削除の説明（何が消え、何が残るか） | ニックネームを変える、アカウントを削除する（確認の画面でパスワードを入力する） |
| S-13 | プライバシーポリシー | 個人情報の使い方、変更した日 | ― |
| S-14 | 利用規約 | 利用のルール、変更した日 | ― |
| S-15 | お知らせ一覧 | お知らせの一覧（例：「○○勉強会で、締め切り後のキャンセルがありました」）、未読・既読 | お知らせを開くと既読になり、該当するイベント詳細へ移動する |
| S-99 | ページが見つかりません | 案内の文章 | トップへ戻る |

ボタンは、その操作ができる人にだけ表示します。ただし、これは使いやすさのためで、権限の本当のチェックはバックエンドで行います。

## 3. 画面の移動

```
S-01 コミュニティ一覧
 ├─ S-04 コミュニティ作成 ──（作成後）──→ S-05
 └─ S-05 コミュニティ詳細
     ├─ S-06 コミュニティ編集
     ├─ S-07 メンバー管理
     ├─ S-08 イベント作成 ──（作成後）──→ S-09
     └─ S-09 イベント詳細
         ├─ S-10 イベント編集
         └─ S-11 申込者一覧

画面上部（全画面共通）：ロゴ（S-01 へ）、ログイン（S-03 へ）、アカウント登録（S-02 へ）、
                        お知らせ（未読の件数つき、S-15 へ）、アカウント設定（S-12 へ）、ログアウト
画面下部（全画面共通）：プライバシーポリシー（S-13 へ）、利用規約（S-14 へ）
```

ログインが必要な画面に、ログインしていない状態で来た場合は、S-03 ログインへ移動します。
