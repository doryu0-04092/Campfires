# 法的な論点のメモ

このアプリに関係する日本の法律と、それぞれに「対応する・しない」の判断をまとめます。

> **注意**：法律の専門家ではない立場で調べたメモです（2026年9月28日時点）。本物のサービスとして公開する前には、条文を e-Gov 法令検索で確認し、必要に応じて専門家に相談します。「不確か」と書いた点は、特に確認が必要です。

## 1. 前提

- **個人情報保護法は、適用される前提で設計する。** 法律の「事業」は営利かどうかを問わない。無料のポートフォリオでも、実在の人の名前やメールアドレスを集めて公開するなら、適用されると考えるのが安全（適用されるかどうかは不確か）
- **2026年7月に個人情報保護法の改正が成立した。** 施行は公布から2年以内（遅くとも2028年7月）。16歳未満の子どもの個人情報について、保護者の関与が必要になる。施行日と細かい内容は、政令とガイドラインを待つ必要がある（不確か）

## 2. 対応の判断

| 論点 | 関係する法律 | 判断 | 対応する場所 |
|---|---|---|---|
| プライバシーポリシーの公開と、登録時の同意 | 個人情報保護法 21条・32条 | **対応する** | F-18、S-13 |
| 利用規約の公開と、登録時の同意 | 民法 548条の2〜4（定型約款） | **対応する** | F-18、S-14 |
| アカウント削除と個人情報の消去 | 個人情報保護法 22条・35条 | **対応する** | F-17、S-12 |
| 安全管理の措置（パスワードの変換、HTTPS、Cookie の設定、権限チェック） | 個人情報保護法 23条、不正アクセス禁止法 8条 | **対応する** | [非機能要件](non-functional-requirements.md) 3章 |
| 他人に見せる個人情報を最小限にする | 個人情報保護法 23条・27条 | **対応する**。本名とニックネームを分け、ほかのユーザー（オーナーと運営スタッフを含む）にはニックネームだけを見せる。本名は本人と管理者だけが見られる | 要件定義書 5.6 |
| ニックネームをオーナーと運営スタッフに見せること | 個人情報保護法 27条（第三者への提供） | **プライバシーポリシーに書き、登録時の同意で対応する**（下の説明を参照） | F-18、S-02、S-13 |
| イベントの場所に個人の住所が書かれること | 民法 709条（プライバシーの侵害） | **対応する**。イベントを作る画面で、個人の住所を入力しないよう注意書きを出す | 要件定義書 5.2、S-08、S-10 |
| 情報が漏れたときの報告 | 個人情報保護法 26条 | **手順だけを文書にする。機能は作らない**。報告は管理者（運営者）の仕事なので、アプリの機能は不要 | この文書の 3章 |
| 書き込みへの通報の窓口と、運営者による削除の機能 | 情報流通プラットフォーム対処法 3条 | **対応しない**（下の説明を参照） | ― |
| 電気通信事業の届出 | 電気通信事業法 9条・16条 | **不要と判断**。ユーザー同士のメッセージ機能がないため。チャットなどを追加するなら見直す（不確か） | ― |
| Cookie などの外部送信のルール | 電気通信事業法 27条の12 | **今は関係しない**。アクセス解析などの外部ツールを入れるときに見直す | ― |
| 広告メールのルール | 特定電子メール法 | **今は関係しない**。メール通知を作らないため | ― |

### ニックネームを見せることの整理

オーナーと運営スタッフは、管理者から見ると別の人（第三者）にあたる。ニックネームだけでは誰なのか分からなくても、個人情報にあたるかどうかは**渡す側（管理者）が本人を特定できるか**で判断されるため、ニックネームを見せることも「個人情報の第三者への提供」にあたる可能性がある（不確か）。

そこで、次の2つで対応する。

1. プライバシーポリシーに「ニックネームは、ほかのユーザー（参加したコミュニティのオーナーと運営スタッフを含む）に表示されます。本名とメールアドレスは表示されません」と書く
2. アカウント登録のとき、プライバシーポリシーへの同意をもらう（本人の同意）

本名をほかのユーザーに見せないことで、万が一の場合の被害も小さくできる。

### 通報の窓口と削除の機能を作らない理由

コミュニティやイベントの説明文は、ユーザーが自由に書き込める。他人の悪口や個人情報が書かれたとき、運営者が知っていながら放置すると、責任を問われる可能性がある。通報の窓口や、運営者が書き込みを非表示にする機能があると、この責任を小さくできる。

ただし、このアプリはポートフォリオであり、実装の量を抑えるため、**このリスクを理解した上で、通報と削除の機能は作らない**と判断した。本物のサービスとして公開する場合は、最優先で追加する。

## 3. 情報が漏れたときの報告の手順

アプリの機能としては作らず、管理者（運営者）が行う手順として定める。

### 3.1 報告が必要になる場合

次のどれか1つに当てはまる漏えい（またはそのおそれ）があったら、国（個人情報保護委員会）への報告と、本人への通知が必要になる。

| 番号 | 内容 | このアプリで当てはまりうる例 |
|---|---|---|
| ① | 病歴など、特に配慮が必要な個人情報が含まれる | 通常は集めないので、当てはまりにくい |
| ② | お金の被害が出るおそれがある | 決済がないので、当てはまりにくい |
| ③ | **不正な目的で行われたおそれがある** | **不正アクセスで、データベースの中身が盗まれた。この場合は人数に関係なく、1人分でも報告が必要** |
| ④ | 1,000人を超える | 登録者が 1,000人を超えていて、全件が漏れた |

登録フォームに悪意のあるスクリプトが仕込まれ、入力中の情報が盗まれた場合も、③に含まれる。

### 3.2 手順

| 段階 | 期限 | やること |
|---|---|---|
| 1. 気づく | ― | 不審なアクセス、利用者からの問い合わせ、エラーの急増などで気づく |
| 2. 被害を止める | すぐに | 不正なアクセスを遮断する。パスワードや鍵を変える。必要ならアプリを止める |
| 3. 証拠を残す | すぐに | アクセスのログ、データベースの操作の記録を消さずに保存する |
| 4. 範囲を調べる | すぐに | いつから、誰の、どの情報（名前、メールアドレス、パスワードの変換後の値）が漏れたか |
| 5. 報告が必要か判断する | すぐに | 3.1 の①〜④に当てはまるか |
| 6. 国に速報する | 気づいてから**3〜5日以内** | 個人情報保護委員会の Web の報告フォームから送る。分かっている範囲でよい |
| 7. 本人に通知する | 速やかに | 何が起きたか、どの情報が漏れたか、本人にしてほしいこと（同じパスワードを使っているほかのサービスでの変更など） |
| 8. 国に確報する | 気づいてから**30日以内**（③の場合は**60日以内**） | 調べ終わった内容をすべて報告する |
| 9. 再発を防ぐ | ― | 原因を直し、何をしたかを記録する |

### 3.3 報告する内容

- 何が起きたか（概要）
- 漏れた個人情報の項目（名前、メールアドレスなど）
- 漏れた人数
- 原因
- 二次被害のおそれがあるか、あるならその内容
- 本人への対応の状況
- 公表したかどうか
- 再発を防ぐための対策

### 3.4 そのほか

- 不正アクセスが原因のときは、警察（都道府県警察のサイバー犯罪相談窓口）への相談も行う
- 報告先：個人情報保護委員会「漏えい等の対応とお役立ち資料」 https://www.ppc.go.jp/personalinfo/legal/leakAction/ （URL は公開前に確認する）

## 4. 規約とポリシーを書くときの注意

画面（S-13、S-14）を作るときに、次の点を守る。

### プライバシーポリシー

- 利用目的を具体的に書く（アカウントの管理、コミュニティとイベントの運営、ニックネームをほかのユーザーに表示すること、問い合わせへの対応、不正な利用の防止）
- 本名とニックネームの扱いを分けて書く。ニックネームはほかのユーザー（オーナーと運営スタッフを含む）に表示されること、本名とメールアドレスは本人と管理者だけが見られること、本名を何に使うか（本人確認、問い合わせへの対応、不正な利用への対応）
- 開示・訂正・削除などを求める方法と、問い合わせの窓口を書く
- 安全管理のために行っていることを書く
- データを保存する国を書く（海外のクラウドを使う場合）
- 運営者の住所は、「求めがあれば遅滞なく回答する」と書けば、ページに載せなくてよい

### 利用規約

- 「運営者は一切責任を負いません」のような、すべての責任を免れる書き方をしない。消費者契約法で無効になる
- 責任を制限するなら、「運営者の軽い過失による場合に限り」と明記する
- 禁止事項を書く（他人の個人情報や自宅の住所の掲載、なりすまし、他人への悪口、著作物の無断転載）
- 規約を変えるときの手続き（事前に知らせる、変えた日を書く）を書く
- 「アカウントはいつでも削除できる」と書く
- 16歳未満は利用できないと書く。2026年の個人情報保護法の改正で、16歳未満の個人情報には保護者の関与が必要になるため
- パスワードを忘れた場合と、本名やメールアドレスを変えたい場合は、問い合わせで対応すると書く
